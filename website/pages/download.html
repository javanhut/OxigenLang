Download Oxigen

{{release_summary}} Prebuilt for Linux and macOS, on x86-64 and ARM64. The Linux builds are static, so they run on any distribution.

One command

Paste this into a terminal. It works out your system, downloads the matching build, checks its SHA-256 against the one GitHub published, and installs it.

shell
{{install_command}}

It installs to ~/.local, or to /usr/local when run as root, and tells you if that isn't on your PATH. Read the script before you run it; it's short.

Choose a version or a location, or uninstall
shell
# a specific version
curl -fsSL https://www.oxigenlang.org/install.sh | sh -s -- --version {{version}}

# somewhere else
curl -fsSL https://www.oxigenlang.org/install.sh | sh -s -- --prefix /opt/oxigen

# remove it again
curl -fsSL https://www.oxigenlang.org/install.sh | sh -s -- --uninstall

By hand

Unpack the archive and put it on your PATH. Keep stdlib/ next to the binary.

shell
tar -xzf oxigen_lang_*.tar.gz
cd oxigen_lang_*/
./oxigen --version

On a Mac, a file downloaded in a browser is quarantined. If macOS refuses to open it, run xattr -d com.apple.quarantine oxigen, or use the one-line installer, which doesn't have the problem.

Docker

The same static binaries, on Alpine, for x86-64 and ARM64. Mount your code at /work.

shell
docker run --rm -v "$PWD:/work" javanhut/oxigen:{{version}} hello.oxi

From source

Any system Rust supports. You get the JIT, the LSP if you want it, and the newest code on main.

shell
git clone {{repo}}.git
cd OxigenLang
./scripts/install.sh

Getting started has the details.

On Windows

There's no native Windows build yet. Oxigen runs well under WSL: install it with wsl --install, open the Linux terminal it gives you, and run the one-line installer there.

Not near a terminal? The playground runs the real interpreter in your browser, nothing to install.
