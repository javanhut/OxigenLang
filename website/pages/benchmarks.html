All of it

Fastest run of each program, in milliseconds. Default is plain oxigen file.oxi: hot functions go native after about 50 calls. --jit compiles on the first call. --no-jit is the interpreter alone, and it's slower than CPython. The JIT is what makes the difference.

How they were measured

scripts/bench.sh runs each example/bench_*.oxi next to its Python twin, plus the TypeScript versions under Bun and Node where there are any. Runs are interleaved, A then B then A, so every runtime sees the same thermal state on a laptop that throttles. Each number is the fastest run after warm-ups.

Click a label in the chart to read that program. The JIT itself is written up in JIT architecture.
