Oxigen is a programming language for code that says what it means.

You write it close to how you'd explain the problem out loud. It compiles to bytecode, and the functions you call most are compiled to machine code while the program runs.

A small language with few surprises.

Oxigen keeps one way to do each thing. That's deliberate: when there's one obvious way to write something, you can read anyone's code, including your own from last year.

  1. Fast where it matters

    Programs compile to bytecode. A function that gets called about 50 times is compiled to machine code by a Cranelift JIT. You don't ask for it.

    How the JIT works

  2. Patterns you can name

    Write a condition once with pattern, then pick between them with choose. A long if-chain turns into a list you can read.

    Pattern matching

  3. Types when you want them

    Leave a variable untyped, or write <int> and it stays an int. The VM checks parameter types on every call.

    Type system

  4. Errors you can hold on to

    An error stops the program unless you catch it. Or turn it into a value with <Error>, pass it around, and decide what to do later.

    Errors

  5. Structs and enums

    Structs with typed fields, methods and inheritance. Enums with plain, tuple and struct variants, the way Rust does them.

    Structs

  6. Threads without locks

    diverge hands work to another core and converge gets the answer back. Tasks don't share memory, so there's nothing to lock.

    Concurrency

  7. A standard library you'll use

    {{stdlib_count}} modules: JSON, TOML, regex, an HTTP client and server, TCP and UDP, dates, hashing, files and processes.

    Standard library

  8. Runs inside your Rust program

    Embed the VM in a game or a tool, give scripts only the capabilities you choose, and cap how long they're allowed to loop.

    Embedding

Use every core. Lock nothing.

diverge each runs a block for every item on a pool of threads and gives you the results back in order. Tasks don't share memory; values move between them. There is nothing to lock and no data race to chase.

This one counts the primes below a million on four cores. It needs real threads, so it runs on your machine rather than in the browser.

Tests live next to the code.

Write <test> blocks with expect(...) and run oxigen test. It finds every *_test.oxi file and exits non-zero when something fails, so CI needs no setup.

  • oxigen fmt formats your code; --check fails CI when it's off.
  • oxigen check prints diagnostics as JSON for editors.
  • oxigen explain E0031 tells you what an error code means.
  • A language server, with a ready Neovim setup.

Install it.

You need Rust. It builds on Linux and macOS.

Get the source

Clone it from GitHub.

shell
git clone {{repo}}.git
cd OxigenLang

Build and install

Puts oxigen and the standard library on your path.

shell
./scripts/install.sh

Run something

Or type oxigen on its own for the REPL.

shell
oxigen hello.oxi

The getting started guide goes further: the REPL, script arguments, and the rest of the oxigen command.
