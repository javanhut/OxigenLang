The Oxigen programming language

Oxigen is a general-purpose language with readable syntax, structs and enums, pattern matching and optional type annotations that are checked when the program runs. Programs compile to bytecode, and a Cranelift JIT compiles the functions called most often to machine code.

Created by {{author}}. Open source under MIT or Apache-2.0.

The language

Oxigen aims for one obvious way to write each thing, so code reads the same whoever wrote it.

Bytecode VM and JIT

Programs compile to bytecode. A function called about 50 times is compiled to machine code by a Cranelift JIT, without any annotation.

How the JIT works

Named patterns

Write a condition once with pattern, then branch on it with choose. A long chain of if becomes a readable list.

Pattern matching

Optional types

Leave a variable untyped, or declare it <int> and it stays an int. Parameter types are checked on every call.

Type system

Errors as values

An error stops the program unless it is caught. With <Error> it becomes a value you can pass around and inspect later.

Error handling

Structs and enums

Structs with typed fields, methods and single inheritance. Enums with plain, tuple and struct variants.

Structs

Concurrency without shared memory

diverge runs work on another thread and converge collects the result. Tasks exchange values, not memory, so there are no locks.

Concurrency

Performance

On the benchmark suite, Oxigen {{bench_oxigen}} with the JIT on, which is the default, was faster than CPython {{bench_python}} on {{bench_wins}} of {{bench_count}} programs. The median speed-up was {{bench_median}}×, and the largest {{bench_max}}×, on tight loops. CPython ran with its own JIT enabled.

Without the JIT, the interpreter alone is slower than CPython.

Testing and tools

Write <test> blocks with expect(...) and run oxigen test. It finds every *_test.oxi file and exits non-zero when a test fails.

  • oxigen fmt formats code; --check fails when a file isn't formatted.
  • oxigen check prints diagnostics as JSON for editors.
  • oxigen explain E0031 explains an error code.
  • A language server, with a Neovim configuration in the repository.
